## 这是什么

一款由 **Python + pygame** 编写的暗黑魔幻风格 2D 塔防游戏。10 关完整剧情，5 种防御塔 × 5 种敌人，含 Boss 多阶段战斗、毒液传染、护盾分享、穿透激光、隐身召唤等机制。

游戏名《守护稚码王国》取自机构名"稚码园"——寓意学员用代码守护自己的王国。

它同时也是一台**代码熟练度训练机**：每波敌人打完都会弹一次"神秘口令"，孩子要照着屏幕把一段 **C++ 代码亲手打一遍**，打对了才能领走补给。玩得开心，代码手感不知不觉就练出来了。

## 玩法概览

| 元素 | 详情 |
|---|---|
| **5 种防御塔** | 哨戒弩台(连射) · 霜寒尖塔(减速冻结) · 瘴毒祭坛(毒液传染) · 炼狱火炮(暴击重甲) · 奥术裂隙(穿透激光) |
| **5 种敌人** | 魔化步兵 · 暗影行者(加速光环) · 铁甲魔像(护盾分享) · 深渊领主(Boss) · 幽冥飞灵(直线飞行) |
| **10 关** | 边境村庄 → 幽暗森林 → 腐败沼泽 → 远古墓地 → 废弃堡垒 → 恶魔要塞 → 熔岩洞窟 → 暗影深渊 → 恐惧王座 → 地狱深渊 |
| **3 档难度** | 简单(敌人HP×0.7,无密语) · 普通(标准) · 困难(敌人HP×1.3,生命-5) |
| **打码补给** | 波波都要写代码：1-3 波关键字 → 4-5 波单行 → 6-7 波多行 → 8-9 波完整小题 |

### 塔 vs 兵种克制

```
弩台  →  杂兵群
冰塔  →  中速兵
毒塔  →  重甲群
火炮  →  重甲单体
激光  →  Boss / 隐身单位
```

### Boss 战（深渊领主）

- **每 7 秒** 减速最近的 2 座防御塔（持续 4 秒，攻速降至 70%）
- **血量 < 50%** 时进入 2 秒隐身 + 召唤 5 个增援

## 边玩边练 C++：打码补给

这是本作和别的塔防最不一样的一处：**想要补给，就得写代码**。

每一波敌人清空后等待 1 秒，会弹出"神秘口令"——屏幕上给出一段 C++ 代码，照着打一遍，全打对立刻到账；不想打点「放弃补给」就行，什么都不扣，游戏继续。

**补给规则**

| 项目 | 规则 |
|---|---|
| 触发时机 | 第 1 ~ 第 9 波，每波清完都弹（第 10 波打完直接通关，不再出题） |
| 金币公式 | `(关数-1)×10 + 波数×10`（第 1 关第 1 波 10 金币，第 9 波 90；第 2 关第 1 波 20） |
| 难度递进 | 1-3 波认关键字 → 4-5 波单行语句 → 6-7 波多行片段 → 8-9 波完整小题 |
| 漏怪补救 | 累计漏怪 7 个另弹一次，打对回 2 点血（兜底，不是救命稻草） |

**题库覆盖的范围** —— 全部取自 C++ 最常用写法，对应 **GESP C++ 一至四级**高频考点：

- 变量与类型 `int / double / char / bool`，标准输入输出 `cin / cout`
- 运算符与表达式、自增自减、整除取余（`%` 与 `/` 的区别）、累加累乘
- 分支 `if / else / else if`、`switch-case-default`
- 循环 `for`（正序/倒序/步长）、`while`、`do-while`，以及 `break / continue`
- 数组定义与遍历、二维数组、求最大值 / 求和 / 斐波那契等经典小题
- 完整小题：两数比大小、成绩分档、九九乘法表等真题写法

**打字的细节都为孩子想过**：支持中文输入法（切换英也不影响）、退格删除、Tab 缩进、回车换行并自动继承上一行缩进；空格数量和全角标点不计较（那是输入法的问题），但**缩进必须真的打出来**——不打缩进练不会代码结构。

## 激活码说明

游戏内置 **7 天试用**（从第一次运行起算），到期后需要激活码继续游玩。激活码**离线校验、绑定机器**：一码对应一款游戏 + 一台电脑，且只能用一次；到期续期需要新的码。

把游戏里显示的 **8 位「申请码」**（形如 `A3K7-M2XQ`，只与硬件有关，不含隐私）发给作者，即可换取 **21 位激活码**。

> 本仓库**不包含密钥**：`game/license_key.py` 已被 `.gitignore` 排除，clone 下来照常能玩，只是「输入激活码」未配置。自建发码体系时，把同目录下的 `license_key.py.example` 复制为 `license_key.py` 并填入密钥即可。

## 运行方式

### 系统要求
- Python 3.8 及以上
- pygame ≥ 2.0

### 安装与启动

```bash
# 1. 克隆或下载代码
git clone <repo-url>
cd TowerDefense

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动游戏
python main.py
```

### 打包为 exe

```bash
pyinstaller TD.spec
# 产物在 dist/守护稚码王国/守护稚码王国.exe（带 assets 与 data 资源）
```

## 项目特色

本项目由稚码园机器人编程团队独立设计开发，注重工程化与可玩性：

- **全中文注释 + 类型提示**：代码关键路径、类、核心方法均有说明
- **配置外置**：`levels.json` 改动路径无需改代码
- **单一职责**：渲染与逻辑完全分离（`renderer.py` vs `game.py`）
- **数据驱动**：核心数据结构（`TowerStats`/`EnemyStats`/`PathStyle`）使用 `@dataclass`
- **性能优化**：粒子、激光用环形索引复用，避免运行时 GC

## 这个游戏对学员意味着什么

做这个项目的起点很简单：**让小朋友相信，学习编程不只是在屏幕前敲字母，而是真的可以亲手创造出一个自己喜欢的东西——可以是自己设计的游戏，可以是自己想象中的世界。**

这件事听起来很遥远，但这个项目本身就把"从零到一"走了一遍：先有想法，再有玩法，再有画面，再打磨平衡，最后变成一个真正能玩的程序。我们希望它能成为一个**学员既可以玩、也可以拆开看的样本**。

具体来说：

- **看一个程序是怎么长大的**。一个完整的项目由哪些部分组成？配置怎么写？资源怎么管？状态机怎么跑？这里都能看到
- **从 GitHub 下载，自己跑起来**。完整代码、注释齐全，按照 [运行方式](#运行方式) 几步就能启动
- **拆开读，改一改**。每个文件职责清晰，参数集中在 `config.py`，改一个数值、改一张图、加一个塔，立刻能看见发生了什么
- **发现"隐藏的秘密"本身就是乐趣**。通关密语藏在特定难度的结局里，每种塔与每种兵的克制关系不会写在表面，敌人 AI 的细节也没有注释提醒——这些都留给愿意仔细观察的小小探索者

我们想表达的就一件事：**玩中学，慢慢提高信息素养。** 做这个游戏的初衷，就是希望小朋友在喜欢玩的东西里，看见代码能做到的事，然后知道自己也可以。

### 不教孩子背代码，让孩子在创造里用熟它

这也是这一版加入「打码补给」的原因。传统练打字是枯燥的，但把代码嵌进游戏进程里就不一样了：

- **有动机**：不是为了写作业才打，是为了拿补给打赢下一波才打
- **有梯度**：从认单个关键字起步，一路打到完整小题，不会一上来就劝退
- **高频重复**：一局九次、一关接着一关，同样的 `for`、`cout`、`switch` 会反复过手 —— 熟练度就是这么磨出来的
- **零负担**：打错不扣任何东西，随时能放弃，家长不用在旁边盯着

孩子不会觉得自己在"学习"，但一学期下来，`int main()` 怎么打、`for` 循环怎么写、数组怎么定义，手已经记住了。
